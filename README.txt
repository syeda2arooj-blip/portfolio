# Arooj Fatima Portfolio

A free, self-contained HTML/CSS/JavaScript portfolio.

## How to open it
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html`.
4. Install the free VS Code extension **Live Server**.
5. Right-click `index.html` -> **Open with Live Server**.

## How to edit
Open `index.html` and search for the section you want:
- HOME
- ABOUT
- SKILLS
- SERVICES
- PROJECTS
- EDUCATION
- CONTACT

### Change profile picture
Replace:
`assets/profile.jpg`

Keep the same filename, or change the `<img src="...">` path in `index.html`.

### Change CV
Replace:
`assets/Arooj-Fatima-CV.pdf`

Keep the same filename so the Download CV button continues to work.

### Change colors
Open `style.css` and edit the variables at the top:
`--gold`, `--bg`, `--text`, etc.

### Add social links later
Add links inside the footer in `index.html`, for example:
<a href="YOUR-LINK">LinkedIn</a>

No paid service is required to run this portfolio locally.
For a public website, you will need hosting and usually a domain. GitHub Pages can host a static HTML/CSS/JS portfolio for free if its current terms/features support your use case.
